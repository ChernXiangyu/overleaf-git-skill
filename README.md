# overleaf-git — a Claude Code skill

A [Claude Code](https://claude.com/claude-code) skill for working with [Overleaf](https://www.overleaf.com)
projects through their git integration: clone a project, authenticate with a git token, pull what
coauthors wrote in the editor, push tables and figures generated by your code, and avoid the traps.

It is built for the common research setup: **a paper whose tables and figures come out of a code pipeline
(Stata, R, Python), while coauthors write the prose in the Overleaf editor.**

## What it teaches Claude

- **Setup**: git URLs, token authentication (username `git`), storing the token in the OS keychain so it is
  never pasted into chat, scripts or remote URLs.
- **The daily loop**: pull → regenerate → push, and why Overleaf commits appear "just in time".
- **The limitations that bite**: no branches (push to `main`), renames destroy comments and tracked
  changes, no symlinks, no LFS, no execute bit.
- **The decision that matters — push from git, or edit in the editor?** Generated files flow
  code → Overleaf and are never edited there; prose flows Overleaf → your backup and is never pushed.
- **Troubleshooting**: `Repository not found`, authentication failures, rate limits, pushes rejected while
  a collaborator is typing (pull `--rebase` and retry), stale images from Overleaf's cache.

Everything is sourced from Overleaf's documentation (links in `SKILL.md`), except a clearly labeled
section of field experience.

## Contents

| File | Purpose |
|---|---|
| `SKILL.md` | The skill: instructions Claude loads when the task involves Overleaf + git |
| `scripts/sync_generated_files.sh` | One-way sync: pushes generated files (tables, figures, macros) to Overleaf, pulls coauthor-owned files as a backup, retries when a push is rejected because someone is typing |

## Install

Personal (all your projects):

```bash
git clone https://github.com/ChernXiangyu/overleaf-git-skill.git ~/.claude/skills/overleaf-git
```

Or per project: clone into `<project>/.claude/skills/overleaf-git`.

Claude Code picks the skill up automatically. It triggers when you mention Overleaf together with git,
syncing a paper, pushing tables to Overleaf, pulling a coauthor's edits, or Overleaf git tokens.

## Requirements

- Overleaf git integration is a premium feature on Overleaf Cloud (the project owner needs a paid plan),
  or Overleaf Server Pro with the git-bridge enabled.
- `git`; `rsync` for the sync script.
